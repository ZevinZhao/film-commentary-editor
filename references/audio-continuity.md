# 影视解说的原声连续性与混音规程

适用于原片对白切入中文解说时，配乐、环境声、动作声或句尾余韵突然消失的修订。
目标是保留原片的声场与情绪，同时让中文清楚；所有参数都应按当前素材调整。
本文的“底声”包括原片配乐、风声、脚步、衣物声、呼吸等，不等同于额外添加的 BGM。

## 先锁定修订范围

- 用户只要求修声音时，保留已认可的文案、声线、语速、画面、字幕及全局时码。
- 从已认可版本复制视频流，重新混音后只替换音轨；不要顺手重剪或重新生成旁白。
- 先保留旧版和音频中间文件，导出独立修订版，便于同一时间点对比。
- 判断用户说的“音乐”究竟是原片配乐、环境声，还是独立添加的音乐轨。
- 不用新音乐掩盖原片底声被截断的问题；没有必要时也不先做音源分离。

## 1. 建立声音的时间地图

对每个待修入口记录以下项目；不要只记画面切点。

| 项目 | 记录内容 |
|---|---|
| 成片接点 | 原声块结束、解说块开始的时间 |
| 中文实际起声 | 第一字与可听呼吸的时间，可能晚于块起点 |
| 上一段源音终点 | 对应原电影文件的绝对秒数 |
| 下一句原片对白 | 最早可辨词音的起点，而非字幕出现时间 |
| 可用原声尾巴 | 上一段终点至下一句对白前的安全区间 |
| 下一原声场面 | 是否有可以提前进入的无台词动作声或配乐 |
| 源与成片映射 | 连续、跳时、重复，或来自另一份时间基准不同的片源 |

- 原声尾巴可能只有几百毫秒，不把一整段留白误算成切点之后还能延续的长度。
- 先检查现有字幕和逐词记录，再对临界区间单独转写或试听。
- 自动字幕起止时间可能偏移；保守采用更早的下一句起点，并给词头留余量。
- “没有台词”允许有风声、喘息、动作；这些声音可能正是用户想保留的气口。
- 对白按完整语义和表演保留，不能为凑整秒切掉词尾、回答或紧随其后的反应。

## 2. 区分原声自然变化与剪辑增益断点

先确定听到的是自然收声、源片换场，还是混音包络突然变化。

1. 在接点前后选择短窗口，避开中文旁白起声、硬淡变和明显瞬态。
2. 对成片测相同长度窗口的 RMS，并记录 dBFS；短窗口不适合用综合 LUFS 判断。
3. 对原片相对应的同一声音窗口做相同测量，保持声道与采样率一致。
4. 计算成片的前后电平差，再减去原片本身的前后电平差。
5. 同时看波形、试听衔接，解释测量中是否混入对白、脚步或镜头时间跳跃。

```text
人为增益阶跃 ≈ (成片后窗 dBFS − 成片前窗 dBFS)
             − (原片后窗 dBFS − 原片前窗 dBFS)
```

- 原片句尾本来就在衰减，修订目标不是强行把两侧 RMS 拉成相同。
- 如果两侧不是同一连续源音，以上差分不能直接当作严格的增益测量。
- 旁白与底声叠加后，总电平会被人声主导；应另测底声轨，不能据总电平判断音乐没掉。
- “上一块 −23 LUFS、下一块 −40 LUFS”不代表实际只下降 17 dB。
- 逐块 loudnorm 依据各块对白、静音和音乐比例计算增益，局部断点可能超过 30 dB。
- 不把整条原片轨归一化到很低的响度，作为解决英语对白与中文冲突的唯一办法。

## 3. 延续同源原声，再处理对白退出

先做可验证的短尾延续；需要更长底声时，再考虑同源分离。

- 让音轨从上一原声段的源终点继续，画面换镜头不必让声音同时换源时间。
- L-cut：画面已经切到解说段，上一段的气口、配乐和环境声仍自然延续。
- J-cut：下一场面原本的脚步、环境声或配乐提前进入，为下一段原声建立连接。
- J-cut 也要核查词音：不能把下一句人物对白提前盖到仍在说话的中文上。
- 原声与解说开头不一定需要空出绝对静音；没有争抢语义的底声可以自然重叠。
- 延续轨应继承接点前的增益，不要把短尾单独做响度归一化。
- 可用上一段末尾同源 PCM 与已处理 PCM 的 RMS 比值估计增益，窗口太静时改取稳定区间。
- 该估计是边界局部值；原段若有动态处理，不把它误认为全段唯一固定增益。
- 短尾先保持原声连续，再在下一句英语开始前完成对白退出；不要为了“长气口”越过词头。
- 不把同一段源音同时留在旧底轨和新增 L-cut 轨中，避免叠加增益、梳状滤波或回声。

对白即将重新出现时，可按素材选择：

| 情况 | 优先处理 |
|---|---|
| 只需保留短气口 | 连续原声尾巴平缓退出，保留已有安静环境 |
| 同源底声可独立取得 | 在下一句英语前交叉淡化到该底声 |
| 配乐或环境必须继续，但与英语混在一起 | 对所需原片区间做本地对白分离 |
| 分离质量不可用 | 缩短尾音、保留真实的无台词段；明确局限 |

不要循环极短的喘息或动作尾声，也不要用长混响伪造原片并不存在的持续声。

## 4. 平滑包络与交叉淡化

- 分开控制两件事：原英语何时退出，以及底声在中文下何时降低。
- 原轨转到底声的交叉淡化可较短；底声本身的衰减可以跨过中文起声，保留情绪。
- 以中文实际起声和原片下一句的安全边界设置包络，不按每个字幕或镜头重新压音量。
- 底声与原轨来自同源、且逐样本对齐时，优先用互补权重，两个权重之和为 1。
- 同源音乐高度相关，盲用等功率交叉淡化可能在中间把共同内容抬高。
- 对不同源、不同时间的声音，再根据相关性与听感选淡化曲线，不套同一规则。
- 可用余弦或其他平滑 S 曲线；避免在段边界把整条混音先淡到零、再重新淡入。
- 对正的线性增益，可在 dB 域平滑插值，使听感变化更均匀。
- 下降量、保持时间和恢复时间按场面确定；轻环境声不必被抬成配乐的存在感。
- 中文之间的小停顿不要让背景逐词抽动；优先按短语或整段安排缓慢恢复。
- 在下一段原声到来前，逐渐接近它真实的底声增益，检查是否突然“弹响”。

### 零增益的对数陷阱

```text
dB = 20 × log10(线性增益)
```

- 0 dB 表示线性增益 1；线性增益 0 才是静音，不要混用。
- 对 0 取对数会得到负无穷，插值端点还可能出现 0 × 无穷导致 NaN。
- 需要淡到静音时，直接使用能到零的线性幅度窗，或把正增益插值与最终置零分开。
- 若中间计算采用极小正数下限，仍应明确处理真正静音的终点，不能依赖浮点巧合。
- 对生成的增益包络、混音 PCM 检查有限值、峰值和端点连续性，再进入编码。

## 5. 何时使用 MDX 等同源分离

仅在原片配乐或环境需要持续、且新的原英语不能跟随进入时使用；先短段验证。

- 优先复用已安装的成熟 CLI 或已验证推理实现，不临时猜模型张量与频谱参数。
- 核对模型来源、版本或哈希，以及采样率、FFT、频率维、补偿系数和主输出含义。
- 推理代码与模型配置要匹配；名称含“Instrumental”也不代表输出绝对没有人声。
- 优先处理覆盖实际剪辑需求的区间，留出算法所需边缘上下文；不必为两个接点跑整片。
- 在隔离工作环境处理，先确认依赖、权重大小与短段耗时，再决定是否扩大范围。
- 本地分离无需把参考视频或电影音轨上传外部服务；不要悄悄改成在线处理。
- 保留底声与残差两轨；分离模型可能把喘息、衣物或脚步分到任一轨。
- 没有台词的留白优先使用完整原片声场，不应因有了分离轨就把原环境全部丢掉。
- 混音中的“music”文件名只是技术标签；准确称为减弱对白的原片底声。

每次分离至少记录：

- 原片文件标识、截取区间，以及分离文件 0 秒对应的源时间。
- 两轨采样率、声道、样本数、时长、模型哈希与处理参数。
- 是否做过重采样、归一化、补偿、变速或时移；不要分别归一化两个 stem。
- 音频是否有限、非空、未削波，以及边缘是否有填充或截短。
- 两轨相加与输入的重构误差；这只验证配对与幅度记账，不证明分离听感好。
- 保留浮点 PCM 中间文件，合成后再统一管理峰值与交付编码。

## 6. 验证英语残留与环境保留

选真实有原片对白的窗口，比较分离底声与同一时间的未分离原声。

1. 用相同的语言、ASR 模型和设置分别识别两个窗口。
2. 确认未分离原声能识别该台词，避免把模型本来就听不出的低音量误当成去除成功。
3. 检查底声识别出的词是否能对应原台词；音乐中的幻觉文本单独标记。
4. 再检查计划实际使用电平下的底声，关注齿音、词头、低声男性旁白与动作声是否被损坏。
5. 选择无台词窗口比较原声与底声的电平、波形和听感，确认环境没有被过度抽空。
6. 对坏段缩短、换用真实留白或有针对性地重分离，不无止境串联模型。

- ASR 返回空白只代表该次检查未检出可辨词，不证明物理上绝对无人声。
- 原声与底声的总 RMS 差包含音乐和环境变化，不能直接称为“人声抑制了多少 dB”。
- 残差由原声减底声得到时，重构近乎完美是预期结果，不能单独作为音质结论。
- 未经实际试听，不写“听起来完全自然”；分别报告客观测量、ASR结果与人工听审。

## 7. 检查句尾，不用静音长度代替判断

- 结尾距最后可检测声音只有几毫秒，不足以单独判定词尾被切断。
- 检查最后约 300 ms 的能量包络，再放大最后几十毫秒波形。
- 看末音节是否完整衰减、最后样本是否接近零，结合原稿/转写及实际听感判断。
- 对整个词尾仍高能量、波形突切或确实漏字的旁白，回到完整段落重生成或重录。
- 不用追加静音掩盖尚未读完的词；确认自然收声后，才可以在时间线上留正常呼吸。
- 同理，不把保留对白本身的自然衰减误判为混音缺陷，再人为拉平它。

## 8. 导出与验收

- 混音前明确采样率与全局样本数；重采样、延迟和限幅器延迟都要计入同步。
- 不改变已认可旁白的起止位置；限幅、滤波等处理避免引入未补偿的延迟。
- 先检查无 NaN/Inf、无非预期空洞、无溢出，再限幅和编码。
- 导出时复制已认可的视频流，替换音轨；外挂字幕也复制原文件，保留对应关系。
- 核对视频流哈希或等价的视频内容校验，以及字幕内容与时码一致性。
- 核对最终容器的音视频时长、声道、采样率和开头/结尾同步。
- 测最终 AAC 解码后的综合响度、LRA、样本峰值与 true peak；PCM 母带合格不代表 AAC 必然合格。
- 编码可能产生采样间峰值；依据交付标准留余量，必要时调整母带后重编码并复测。
- loudnorm 的测量日志中，input_* 才是被检查文件的实际值；output_* 是滤镜拟产生的结果。
- 不把设置中的 TP 目标值当成最终文件已达到的 true peak。
- 对四类位置重点回放：原声进中文、中文回原声、原画面跳时但底声连续处、最终收尾。
- 对比人工增益阶跃而非只比总 RMS；允许原片原有的动作瞬态和自然动态。
- 交付说明写清改动范围、是否保留原片声场、实际验证结果及仍需听审的局部。
